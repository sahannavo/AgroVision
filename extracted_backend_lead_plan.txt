Common rules You are helping finish the back end of AgroVision (SE205.3), a Flutter and Firebase app for nightshade crop farmers in Sri Lanka. The front end is finished and runs on fake data. This sprint connects it to the real back end (Firebase Auth, Firestore, Storage, Cloud Functions, FCM) and to the on-device TensorFlow Lite model. The feature freeze is Thu 19 Nov and the code freeze is Mon 23 Nov, so the work is about finishing and connecting, not starting over. Many people work in the same repository, so follow these rules exactly. RULES 1. INSPECT FIRST. Before you write anything: list the files that belong to your task, read them, run their tests, and write a short status with DONE, PARTIAL or MISSING for each item of the task. Then do only what is missing or broken. Never rewrite working code, rename public classes, or change an interface that other people use. 2.
